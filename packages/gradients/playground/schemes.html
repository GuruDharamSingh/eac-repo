The recipes

    
A harmony picks which hues by turning round the colour wheel from your base hue h. A palette mode then turns those hues into five working colours by changing saturation and lightness, and gives each one a job.

    
Harmonies (three hues)

    

      
NameHuesFeels

      
        
Triadich, h+120, h+240Lively and balanced; three equal partners. Let one lead.

        
Split-complementaryh, h+150, h+210Contrast of a complement, with less clash: the two partners sit either side of the opposite.

        
Analogoush−30, h, h+30Calm and close; neighbours on the wheel. Needs light/dark contrast to stay readable.

        
Complementary + neutralh, h+180, grey tinted to hStrongest pull between two hues, steadied by a neutral.

      
    

    
Palette modes (five colours)

    

      
ModeThe fiveGood for

      
        
Tint / shade rampBase hue at lightness 95, 78, base, 30, 13One-colour brands; quiet, very coherent sites.

        
TonesAll three harmony hues with saturation cut to 45%, plus a toned light and darkMuted, earthy, “printed” looks.

        
Triad + 2 tinted neutralsThree harmony hues at full strength, plus near-white and near-black with a hint of the base hueColourful sites that still read cleanly.

        
Triad + primary light / darkThree harmony hues, plus a pale and a deep version of the primary as the page and textStrong identity: even the page ground carries the brand.

        
Monochrome + accent popBase hue as light, base and shade, deep text, plus one vivid colour from the harmonyCalm sites with one thing that must be seen (a Book or RSVP button).

      
    


    
Under the hood

    

      
1. A harmony is a list of turns. Add each turn to the hue and wrap past 360.
const HARMONIES = {
  triadic: [0, 120, 240],
  split:   [0, 150, 210],
};
const turn = (h, o) => ((h + o) % 360 + 360) % 360;
HARMONIES.triadic.map(o => turn(196, o));
// [196, 316, 76]

      
2. Colours are written as tokens inside a [data-brand] block. The site only says var(--color-primary).
[data-brand="live"] {
  --color-primary: hsl(196 58% 40%);
  --surface: hsl(196 10% 97%);
  --text: hsl(196 14% 14%);
}
.site .b1 {
  background: var(--color-primary);
}

      
3. Contrast: turn each colour into relative luminance L, then compare the lighter and the darker.
// L = 0.2126 R + 0.7152 G + 0.0722 B
//     (R, G, B un-gamma'd first)
const ratio = (L1 + 0.05) / (L2 + 0.05);
// 4.5 or more: AA for body text

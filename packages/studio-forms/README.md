# @elkdonis/studio-forms

The light publication-form layer that every org site can install (split out of `@elkdonis/studio` on 2026-11-14; decisions in `docs/open/STUDIO_FORMS_SPLIT_2026-11-14.md`). It holds the Quick-Form and Norm-Form tiers: form kinds (meeting, post, artwork, service), fields, rules, adapters, `FormShell`, themes (`forms.css`, `ledger.css`, `broadsheet.css`), the essay Canvas (`./canvas`, with `./canvas/lazy` for a deferred load), the shared Studio types (`./types`, `./meeting`) and the slice of the Studio frame the forms read (`./host-frame`). `@elkdonis/studio` (Deep-Form) depends on this package, never the reverse. Do not add heavy editors or their dependencies (three, konva, Filerobot, opentype.js, styled-components, Remotion): every site installs this package, and the `.` export must pull in no tiptap module statically, so the blocks editor stays behind `./canvas/lazy`. Harness: `scripts/forms-harness`; rules check: `src/forms/rules/check.ts`.

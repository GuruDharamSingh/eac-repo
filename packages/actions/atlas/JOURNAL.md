## 2026-11-16 · agent A (tooling)
- Built `scripts/atlas-inventory.mts`, `check-atlas.mts`, `atlas-reports.mts`; `package.json` scripts `atlas:inventory`, `atlas:check`, `atlas:reports`. Parser: TypeScript compiler API, syntax only, no type checker.
- Conventions: app = directory name under apps/ or packages/. Inline `"use server"` key is `#<outer top-level symbol>/<fn name | anon0, anon1, ...>` (a default-exported outer is `default`). `export { a as b }` of a local becomes `#b`. Overload signatures are skipped; exported non-function consts (no arrow/function/call initializer) are skipped in sa files. api: one host per exported POST/PUT/PATCH/DELETE. sql: nearest named enclosing function (`Class.method` for methods, top-level wrapped const name, `default`, else `#<module>`); sql writes in packages `services` and `db` are not hosts, only counted in `sharedSqlCount` (services 311, db 10). A function that is an sa/api host and writes raw SQL appears twice, as `sa:`/`api:` (rawSql true) and as `sql:`, so claim both or ignore the sql twin.
- `atlas/index.ts` reads `areas/` dynamically: each file exports an Area as default, or named `AREA`/`area`; AREAS key is the file name; `_`-prefixed files are skipped. Exports `loadAreas()` and `AREAS` (top-level await, Node-only, never import from an app).
- check-atlas: unclaimed = warning unless `--strict`; `--app <name>` scopes. reports: `--wave N` writes wording-wave-NN.md (draft person rows with wave unset or N); it does not stamp rows.
- Counts (2026-11-16): 1987 hosts = sa 879, api 537 (455 route files), sql 571; 5 inline-directive hosts; 201 sa/api hosts with raw SQL; 10 hosts call a registry door; 0 re-exports found. arts-collective: 183 sa, 68 api (55 route files), 25 sql. 
- Blind spots: `calls` only resolves `@elkdonis/*` imports (relative imports such as `./shipping` or `@/lib/...` are invisible, so some hosts show `calls: []`); property calls on named imports (`svc.fn()`) are not resolved, only namespace imports; `registry` does not follow local helper wrappers; SQL built by string concatenation across non-adjacent literals, query builders (no raw INSERT text) and SQL in .sql files or migrations are not seen; mutations done by client components or via fetch to an external service are not hosts; `export * from` is ignored; files outside `src/` are not scanned; `generatedAt` is a date, so same-day reruns are byte-identical.

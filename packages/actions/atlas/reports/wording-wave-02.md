# Confirm wording, wave 02 (dock forms, first batch)

Written by hand on 2026-11-27 (rails desk, lane A). Four new "are you sure?" cards, one for each of the first four forms that open inside the dock. If `atlas:reports --wave 2` is run later it will rewrite this file from the atlas rows, which hold the same text.

## How to answer

When someone presses Save on one of these forms in the dock, a small card asks "are you sure?" first. Below is the card text for each form. Until you approve a card, a normal visitor sees a plain line ("<form name>. This runs now, on your account.") and only you (as an admin) see the draft, marked "Draft wording, not approved yet".

- **Approve:** put an x in "approve" if the card text is right as it is.
- **Change:** put an x in "change to" and write the sentence you want after it.
- None of these four cards has anything in {curly braces}: the card says exactly what is written here.

4 cards.

## 1. Choose where you show (set-where-i-show, the directory switch)

The form is one tick box, "Show my page in the artists’ directory", with a Save button. It turns the listing of the person's own page on or off. It uses the same function as the switch in the profile card.

[Public: other people see the change]

## 2. Create a pen name (create-pen-name)

The form asks for the pen name and has a Create button. It makes a second name the person can write under, with a page address of its own. A pen name is not listed in the directory until its owner lists it, and can be retired later. Photo and details are added afterwards from its own page.

[Public: other people see the change]

> **The card will say:** Create this pen name? It gets a page address of its own. It is not listed in the directory until you choose to list it, and you can retire it later.

**Answer:**  [ ] approve   [ ] change to: ______________________________

## 3. Start a piece of writing (writing-piece-start)

The form asks for a title and has a Start button. It opens a new draft piece in the person's own space. Nothing is published.

[No special risk]

> **The card will say:** Start a draft with this title? It stays a draft in your own space, and nobody else sees it until you publish it.

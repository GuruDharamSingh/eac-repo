### [E] 17:40  Started; fields.ts shape is final (lane F, write against it)
Files now on eris: `packages/actions/src/fields.ts` (types, `declareForms`), `forms.ts` (registry `ACTION_FORMS`, `actionForm(entry)`), `forms-base.ts` (the 7 existing forms as data). Read `fields.ts` for the exact types. Short form:
```ts
ActionForm { entry; fields: FieldSpec[]; load?: readerId; pick?: { reader; label; into?; emptyLabel? }; submitLabel; confirmVars?: {placeholder: fieldName}; needsChange? }
FieldSpec (all have name, label, help?, required?, showIf?: {field, equals}, fillFrom?: {from, label}) by kind:
  text {inputType?: text|email|url|tel|number, maxLength?, minLength?, placeholder?}   textarea {rows?, maxLength?, placeholder?}
  toggle (submits a real boolean)   select {options}   choice {options}   image {library?: readerId}   date (YYYY-MM-DD)   time (HH:MM)   pick {reader}
```
**How to add forms (lane F):** export `export const FORMS_WAVE1: readonly ActionForm[] = [...]` from `packages/actions/src/forms-wave1.ts`, then in `forms.ts` uncomment the two marked lines (import + spread). That is the whole registration. An entry with a declared form is automatically a dock form (catalogue `dockForm` is derived from the registry; you do not touch `DOCK_FORM`). Values are strings, a toggle is boolean; the runner's zod schema stays the authority. Pre-fill: by default the entry's status check `values` (as today); `load: '<readerId>'` names a reader in `packages/actions/src/server/forms.ts` `FORM_READERS` (I add that file; add your reader there with one line). `pick`/`pick` fields read lists through the same `FORM_READERS` (a reader returns `{ values?, items? }`, item = `{id,label,hint?,values?}`); the picked id goes to the run as `subject`.
**Why own vocabulary, not cms-ui `WizardFieldSpec`:** that type sits in cms-ui, which pulls React and compose slots into every site that mounts the dock. Names (name/label/required/options/maxLength/placeholder) match it so an adapter is a few lines; it is a subset, not a fifth vocabulary.
**Image:** no one safe client upload exists across dock hosts (about 20 per-app routes, different checks; UPLOADS_ONE_PATH is still design only). So the dock takes an optional `upload` prop on `<Dock>`; without it the image field is "choose from your pictures" (reader `my-images`, the person's own media rows). No host change needed now.
